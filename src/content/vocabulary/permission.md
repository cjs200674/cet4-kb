# permission

**释义**： 允许， 许可， 准许

**英文释义**： 允许， 许可， 准许

**词性**：n

**搭配 / 词组**：

- without permission: 未经许可
- with one's permission: 如果…允许的话
- written permission: 书面许可证；签单
- ask for permission: 征求许可；请求允许
- planning permission: （英）建筑许可证（建造或改建房屋前必须获得的）
