# panic

**释义**： 恐慌， 惊慌失措；恐慌，惊慌，慌乱

**英文释义**： 恐慌， 惊慌失措

**词性**：v / n

**搭配 / 词组**：

- no panic: [美国俚语]不大高明；平凡
- panic disorder: 惊恐性障碍，恐慌症
- in panic: 惊慌的
- panic attack: 惊恐发作（一种病症）
- financial panic: 金融恐慌；经济恐慌
