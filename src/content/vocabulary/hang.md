# hang

**释义**：挂，悬；吊死

**英文释义**：挂，悬；吊死

**词性**：v

**搭配 / 词组**：

- hang on: 坚持下去；不挂断；握住不放
- hang out: 挂出；闲逛
- hang up: 挂断电话；搁置，拖延
- get the hang of: 得知……的窍门；熟悉某物的用法；理解某事，摸清概况；鉴赏
- hang seng: 香港恒生股票指数；香港恒生银行
