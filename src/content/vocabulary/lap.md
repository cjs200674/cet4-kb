# lap

**释义**： 舔； 拍打；膝部；一圈，一段

**英文释义**： 舔； 拍打

**词性**：v / n

**搭配 / 词组**：

- last lap: 最后一圈；最后阶段
- chek lap kok: 赤鱲角（俗称赤腊角，香港西部海域的一个岛屿）
- lap joint: [建]接搭处
- lap time: 游泳比赛中一次来回所需之时间
- lap up: 舔食；欣然接受
