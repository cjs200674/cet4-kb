# memorial

**释义**：纪念的，悼念的； 纪念碑， 纪念堂， 纪念仪式

**英文释义**：纪念的，悼念的

**词性**：adj / n

**搭配 / 词组**：

- memorial hall: 纪念馆；纪念堂
- memorial day: n. （美国）阵亡将士纪念日
- memorial service: 追悼会；追思礼拜
- lincoln memorial: 林肯纪念堂
- memorial park: 陵园；公墓
