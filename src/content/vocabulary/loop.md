# loop

**释义**： 成环， 成圈；圈，环，回路；循环

**英文释义**： 成环， 成圈

**词性**：v / n

**搭配 / 词组**：

- closed loop: 闭环，闭合环路
- loop control: 循环控制
- loop system: 环形系统，环状管网；闭合系统
- open loop: 开环
- control loop: 控制回路，操纵系统
