# engine

**释义**： 引擎， 发动机； 机车

**英文释义**： 引擎， 发动机； 机车

**词性**：n

**搭配 / 词组**：

- diesel engine: 柴油机（等于diesel）
- search engine: 搜索引擎
- gasoline engine: 汽油机，汽油发动机
- engine oil: 机器润滑油
- combustion engine: 内燃机；燃烧机；内燃机燃烧机
