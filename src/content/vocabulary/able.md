# able

**释义**：有能力的；出色的

**英文释义**：有能力的；出色的

**词性**：adj

**搭配 / 词组**：

- will be able to: 将能够
- be able to do: 能够做
- be able to take: 经受得住某事(指困难、痛苦的事)
- able person: 能人；有能力的人；有用的人才
- spell able: 干练的；有能力的
