# envelope

**释义**：信封；封套；封皮

**英文释义**：信封；封套；封皮

**词性**：n

**搭配 / 词组**：

- flight envelope: 飞行包线
- nuclear envelope: 核膜；核被膜
- envelope curve: 包络曲线；包迹
- failure envelope: 断裂点轨迹；破坏包络线
- push the envelope: 挑战极限；接近甚至超越安全限度；越过底线
