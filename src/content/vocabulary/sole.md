# sole

**释义**： 单独的， 唯一的；脚底，鞋底，袜底

**英文释义**： 单独的， 唯一的

**词性**：adj / n

**搭配 / 词组**：

- sole agent: n. 总代理商；独家经营商；包销人
- sole agency: 独家经理；唯一代理
- sole purpose: 唯一目的
- sole proprietorship: 独资（经营）
- sole discretion: 全权处理
