# utility

**释义**： 效用， 有用， 实用； 公用事业

**英文释义**： 效用， 有用， 实用； 公用事业

**词性**：n

**搭配 / 词组**：

- utility model: 实用新型（约十个国家法律承认的一种保护发明名称，期限五年）
- public utility: 公用设施；公用事业公司
- utility function: 效用函数；应用函数
- utility value: 实用价值，利用价值
- utility theory: 效用理论
