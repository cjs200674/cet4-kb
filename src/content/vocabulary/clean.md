# clean

**释义**：清洁的；纯洁的

**英文释义**：清洁的；纯洁的

**词性**：adj

**搭配 / 词组**：

- clean up: 清理；大捞一笔
- clean water: 清洁（饮）水
- clean energy: 清洁能源
- clean air: 洁净空气；新鲜空气
- keep it clean: [口语]使不弄脏；使不失体统，使不粗野，使不下流
