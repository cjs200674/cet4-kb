# mate

**释义**： 成为配偶， 交配；伙伴，同事；配偶，配对物；大副

**英文释义**： 成为配偶， 交配

**词性**：v / n

**搭配 / 词组**：

- soul mate: 情人；性情相投的人；心心相印的伙伴
- running mate: （美）竞选伙伴
- mate with: 使紧密配合
- chief mate: 大副（等于chief officer）
