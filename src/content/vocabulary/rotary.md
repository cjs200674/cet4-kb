# rotary

**释义**：旋转的，转动的

**英文释义**：旋转的，转动的

**词性**：adj

**搭配 / 词组**：

- rotary kiln: 回转窑；回转炉
- rotary speed: 转速
- rotary screen: 旋转筛；回转筛；旋筛
- rotary table: 转盘，回转台
- rotary club: （美）扶轮社（扶轮国际的分支机构）
