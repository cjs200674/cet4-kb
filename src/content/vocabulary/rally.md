# rally

**释义**： 集合， 团结； 恢复， 重新振作；集会；公路汽车赛

**英文释义**： 集合， 团结； 恢复， 重新振作

**词性**：v / n

**搭配 / 词组**：

- (hold a) rally: 团结；（举行）集会
- pep rally: 赛前动员会，鼓舞士气的集会
- rally point: 集结点
