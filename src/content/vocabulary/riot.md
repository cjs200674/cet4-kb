# riot

**释义**：聚众闹事；暴乱，骚乱；极度丰富； 把浪费在放荡的生活上

**英文释义**：聚众闹事

**词性**：vi / n / vt

**搭配 / 词组**：

- riot police: 防暴警察
- riot in: 沉湎于；热衷于
- run riot: 茂盛；跟错踪迹；胡闹
- riot act: （英）取缔暴动法
- riot gear: 防暴装备
