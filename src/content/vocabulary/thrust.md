# thrust

**释义**：插；戳，刺； 戳， 刺； 要点， 要旨； 推力

**英文释义**：插；戳，刺

**词性**：vt / n

**搭配 / 词组**：

- thrust bearing: 推力轴承；止推轴承
- thrust force: 推力
- axial thrust: 轴向推力
- thrust in: 闯入；不恰当地插入
- thrust out: 逐出；推出；解雇
