# shallow

**释义**：浅的；浅薄的； 浅滩， 浅水处

**英文释义**：浅的；浅薄的

**词性**：adj / n

**搭配 / 词组**：

- shallow water: 浅水；浅海，浅水域；浅滩
- shallow sea: 浅海
- shallow layer: 浅层；薄层
- shallow foundation: 浅基础，浅基
- shallow well: 浅井，浅水井
