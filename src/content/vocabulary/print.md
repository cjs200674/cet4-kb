# print

**释义**：印刷；印刷；正片

**英文释义**：印刷

**词性**：v / n

**搭配 / 词组**：

- in print: 已出版；在销售中
- blue print: n. 蓝图；方案；设计图
- print out: （打）印出
- print media: 平面媒体；印刷媒体
- fine print: （契约中）难懂的条文；极小的字体
