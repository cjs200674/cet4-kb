# peak

**释义**： 达到高峰， 达到最大值；最大值的，高峰的；山顶，顶点

**英文释义**： 达到高峰， 达到最大值

**词性**：vi / adj / n

**搭配 / 词组**：

- peak value: 峰值
- peak load: [经]最大负载
- peak period: 波峰周期；尖峰期
- peak power: 峰值功率，巅值功率
- peak area: [化]峰面积
