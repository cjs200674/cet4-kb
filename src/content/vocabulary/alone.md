# alone

**释义**：单独的；单独地

**英文释义**：单独的

**词性**：adj / adv

**搭配 / 词组**：

- let alone: 更不必说；听任；不打扰
- all alone: 独立地，独自地
- stand alone: 孤立；独一无二
- alone with: 与…一起
- live alone: 独自生活；一个人住；单独居住
