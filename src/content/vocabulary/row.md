# row

**释义**：(一)排，(一)行

**英文释义**：(一)排，(一)行

**词性**：n

**搭配 / 词组**：

- in a row: 连续；成一长行
- front row: 前排，头一排
- single row: 单排；单行
- in row: 行内的；在行内
- death row: 死囚牢房（等于death house）
