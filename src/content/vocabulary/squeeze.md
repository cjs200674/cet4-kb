# squeeze

**释义**：挤；压榨，榨取；捏，握； 挤； 握手； 拮据， 紧缺

**英文释义**：挤；压榨，榨取；捏，握

**词性**：v / n

**搭配 / 词组**：

- squeeze casting: 模压铸造，压挤铸造
- squeeze out: 挤出；榨出；排出
- credit squeeze: 贷款紧缩，银根紧缩
- squeeze in: 榨出，挤出；挤进去
- squeeze into: 挤入…；硬塞进…
