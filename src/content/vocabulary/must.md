# must

**释义**：aux必须；必然要

**英文释义**：aux必须；必然要

**词性**：v

**搭配 / 词组**：

- must be: 一定；一定要；肯定是
- must have: 必须拥有；非有不可
- must have been: 一定（对过去事实肯定的推测）
- must have done: 必定做了…（表示对过去的推测）
- must be going: 该告辞了；必须去
