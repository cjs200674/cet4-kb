# find

**释义**：找到；发觉；找出

**英文释义**：找到；发觉；找出

**词性**：v

**搭配 / 词组**：

- find oneself: 自我感觉；发现自己处于某种状态；发现自己的能力
- find out: v. 找出，查明；发现，揭发
- try to find: 寻求；寻找
- only to find: 结果却发现（表达出人意料或不愉快的意思）
- find what: v. 查找内容
