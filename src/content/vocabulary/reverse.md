# reverse

**释义**：撤销，推翻；反向，倒转；彻底改变； 反向的， 相反的， 倒转的；相反，对立面；反面，背面，后面；挫折，逆境

**英文释义**：撤销，推翻；反向，倒转；彻底改变

**词性**：v / adj / n

**搭配 / 词组**：

- in reverse: adv. 相反，向相反方向，倒（退），逆（行、转等）
- reverse engineering: 逆向工程
- reverse osmosis: 反渗透，逆向渗透
- reverse side: 背面，反面
- reverse circulation: 反循环；逆行循环
