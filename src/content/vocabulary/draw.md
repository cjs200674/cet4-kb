# draw

**释义**：画，划；拖；拨出

**英文释义**：画，划；拖；拨出

**词性**：v

**搭配 / 词组**：

- draw lessons from: 从…吸取教训
- draw up: 草拟，起草；停住；使靠近
- draw on: 利用；吸收；戴上；临近
- draw a conclusion: 得出结论；作结论
- draw out: 取出；拟订；拉长；导致
