# lend

**释义**：把…借给，贷(款)

**英文释义**：把…借给，贷(款)

**词性**：v

**搭配 / 词组**：

- lend itself to: 适用于，适宜于；有助于
- lend a helping hand: 伸出援助之手， 助一臂之力
- lend support to: 支持；支援
- lend an ear: 倾听
- lend out: vt. 租出去；借出
