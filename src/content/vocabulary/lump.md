# lump

**释义**： 结块； 将…归并在一起；块，肿块

**英文释义**： 结块； 将…归并在一起

**词性**：v / n

**搭配 / 词组**：

- lump sum: 总额；汇总
- lump coal: 块煤
- lump ore: 块矿
- in a lump: 一次全部地
- lump sum payment: 整笔付款；一次总算，一次总付
