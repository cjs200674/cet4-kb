# finish

**释义**：完成，结束；结束

**英文释义**：完成，结束

**词性**：v / n

**搭配 / 词组**：

- finish line: 终点线，终航线
- finish with: 完成，结束；与…断绝关系
- surface finish: [机]表面抛光
- finish machining: 精加工；完工切削
- from start to finish: 自始至终；从起点到终点
