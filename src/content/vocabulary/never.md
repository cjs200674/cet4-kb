# never

**释义**：永不，决不；不

**英文释义**：永不，决不；不

**词性**：adv

**搭配 / 词组**：

- never forget: 永不忘记
- never do: 绝对不行，绝不可以
- never mind: 没有关系，不要记在心上
- never before: 以前从未曾有过
- never again: 拒绝再玩，不再；再也不会
