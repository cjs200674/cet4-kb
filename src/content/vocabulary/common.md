# common

**释义**：普通的；共同的

**英文释义**：普通的；共同的

**词性**：adj

**搭配 / 词组**：

- in common: 共同的；共有的
- common people: 大众，平民
- common ground: （争论双方的）共同基础；一致之处
- in common with: 与…一样
- common sense: 常识
