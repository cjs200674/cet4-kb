# backward

**释义**： [-]倒； 向后， 往回；向后的，倒的；落后的，进步慢的

**英文释义**： [-]倒； 向后， 往回

**词性**：adv / adj

**搭配 / 词组**：

- backward area: 落后地区
- step backward: 倒退；返回；逐帧倒放
- backward country: 经济落后国家
- backward extrusion: 反挤压；反向挤压；逆向挤制
- backward compatibility: 向后兼容；反向兼容性
