# interval

**释义**： 间隔， 间距； 幕间休息

**英文释义**： 间隔， 间距； 幕间休息

**词性**：n

**搭配 / 词组**：

- time interval: 时间间隔
- at intervals: 时时，不时；相隔一定距离（或时间）
- confidence interval: 置信区间，可靠区间
- in the interval: 在这一期间；在间隔时
- interval analysis: [计]区间分析
