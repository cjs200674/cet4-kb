# permit

**释义**：允许；执照

**英文释义**：允许

**词性**：v / n

**搭配 / 词组**：

- work permit: 工作许可证
- residence permit: 居留证
- permit of: 允许；容许有
- entry permit: 入境许可证
- import permit: 进口护照；进口准许证
