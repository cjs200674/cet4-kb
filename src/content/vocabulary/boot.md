# boot

**释义**： 靴子， 长筒靴； 行李箱； 解雇

**英文释义**： 靴子， 长筒靴； 行李箱； 解雇

**词性**：n

**搭配 / 词组**：

- boot loader: 引导装载程序
- boot camp: n. ［美口］海军训练新兵之营地
- boot sector: n. 引导扇区；启动磁区
- boot device: 启动设备；引导设备
- boot up: 启动
