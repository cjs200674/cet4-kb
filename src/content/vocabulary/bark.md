# bark

**释义**：吠，叫； 吠声， 叫声； 树皮

**英文释义**：吠，叫

**词性**：vi / n

**搭配 / 词组**：

- bark at: 狗朝着（对着）某人叫；对…狗吠
- tree bark: 树皮绉
- cinnamon bark: 肉桂皮
- pine bark: 松树皮
- cassia bark: 肉桂；桂皮
