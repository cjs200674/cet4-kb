# pilot

**释义**： 试验性的， 试点的；引航员；飞行员；驾驶；为引航；试验，试用

**英文释义**： 试验性的， 试点的

**词性**：adj / n / vt

**搭配 / 词组**：

- pilot test: 小规模试验；初步试验
- pilot project: 试点项目，试点工程；样板工程，样板设计
- pilot study: n. 初步研究；预备试验；飞行员研究
- pilot plant: n. 试验工场；小规模试验厂
- pilot scale: 中试规模；试验性规模
