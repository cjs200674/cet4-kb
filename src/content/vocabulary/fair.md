# fair

**释义**：公平的；相当的

**英文释义**：公平的；相当的

**词性**：adj

**搭配 / 词组**：

- fair play: 公平竞争；公平比赛；平等对待
- fair competition: 公平竞争
- fair value: 公允价值；[经]公平价格
- trade fair: 商品交易会；贸易展销会
- fair trade: 公平贸易；互惠贸易
