# variable

**释义**：易变的； 变量

**英文释义**：易变的

**词性**：adj / n

**搭配 / 词组**：

- variable speed: 变速，可变速率
- random variable: 随机变数，随机变量；无规变量
- state variable: [控制系统]状态变量；[热力学]热力学态函数（等于thermodynamic function of state）
- independent variable: 自变量；自变数
- dependent variable: 因变量；他变数；应变数
