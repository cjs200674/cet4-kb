# implement

**释义**：实施；执行；工具

**英文释义**：to put a plan into action; a tool

**例句**：
- The government **implemented** a new policy.
- We need to buy some gardening **implements**.

**搭配**：
- implement a plan / policy 实施计划/政策
- implement reforms 推行改革
- farming implements 农具

**派生**：
- implementation (n.) 实施
- implementer (n.) 实施者

**辨析**：
- implement "实施"，强调执行
- execute "执行、完成"
- carry out "执行、开展"

**记忆法**：`im-`(进入) + `ple`(填满，源于 full) + `-ment` → 填满到执行 → 实施
