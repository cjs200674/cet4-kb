# visual

**英文释义**：看得见的

**词性**：adj / n

**搭配 / 词组**：

- visual angle: n. 视界，视角
- visual effect: 视觉效果；视觉特效，视觉效应
- visual field: 视野
- visual acuity: 视敏度
- visual system: n. 视觉系统，目视（光学）系统
