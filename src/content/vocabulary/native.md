# native

**释义**：本土的；本地人

**英文释义**：本土的

**词性**：adj / n

**搭配 / 词组**：

- native place: 籍贯
- native american: 印第安人；美洲原住民
- native language: 本国语言；本机语言；机器各单元间编码语言
- native land: 祖国；家乡
- native speaker: 说母语的人，说本族语的人
