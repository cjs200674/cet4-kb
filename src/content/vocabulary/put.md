# put

**释义**：放，摆；使处于

**英文释义**：放，摆；使处于

**词性**：v

**搭配 / 词组**：

- put forward: v. 提出；拿出；放出；推举出
- put in: 提出，提交；放入；种植；使就职
- put on: 穿上；上演；增加；假装；使…上场
- put into: 使进入；把...放进；在……上种植
- put up: 提供；建造；举起；推举，提名；供给…住宿
