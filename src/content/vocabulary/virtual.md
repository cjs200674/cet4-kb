**搭配 / 词组**：

- virtual reality: 虚拟现实
- virtual world: 虚拟世界；虚像世界
- virtual machine: 虚拟机，虚拟计算机
- virtual memory: 虚拟内存
- virtual network: 虚拟网络；虚拟网路
