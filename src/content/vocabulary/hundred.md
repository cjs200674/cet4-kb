# hundred

**释义**：百，百个；许多

**英文释义**：百，百个

**词性**：num / n

**搭配 / 词组**：

- one hundred: 一百
- five hundred: 五百分（牌戏，一种以得500分为胜局的游戏）
- four hundred: 名流；绅士
- one hundred percent: 百分之百；不折不扣
- hundred flowers: 百花齐放，百花
