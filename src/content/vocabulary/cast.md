# cast

**释义**：投，扔，抛；浇铸； 演员表， 全体演员； 石膏绷带； 铸型， 铸件； 投， 抛

**英文释义**：投，扔，抛；浇铸

**词性**：vt / n

**搭配 / 词组**：

- cast iron: 铸铁，生铁，锻铁
- cast off: 摆脱；抛弃；解开（缆绳等）
- cast steel: 铸钢，坩埚钢
- cast in: 镶铸
- white cast iron: 白口铸铁
