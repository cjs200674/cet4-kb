# bore

**释义**：使厌烦；钻，挖； 令人讨厌的人

**英文释义**：使厌烦；钻，挖

**词性**：vt / n

**搭配 / 词组**：

- bore hole: 钻孔；炮眼
- bore diameter: 孔径，内径
- cylinder bore: 缸膛
- full bore: 贯眼；等径孔道；全孔射击
- tidal bore: 涌潮，怒潮；潮津波
