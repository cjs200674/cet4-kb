# better

**释义**：较好的；更好地

**英文释义**：较好的

**词性**：adj / adv

**搭配 / 词组**：

- better than: 超过；多于；好于…
- better than oneself: ◎所做的比所答应的好
- had better: 最好
- much better: 更好；好多了；好得多
- you'd better: 你最好...（等于you had better）
