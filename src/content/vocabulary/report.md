# report

**释义**：报告；汇报

**英文释义**：报告；汇报

**词性**：vt&vi

**搭配 / 词组**：

- report oneself: 去报到；到…去见某人
- report of: 说出对…的印象；…的报告
- report on: 就…作报告
- annual report: 年报，年度报告；年度决算；年度财务报告
- report for: 由于…而告发；为…作报道
