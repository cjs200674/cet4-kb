# effect

**释义**：结果；效果，效力

**英文释义**：结果；效果，效力

**词性**：n

**搭配 / 词组**：

- effect on: 对…的作用
- curative effect: 疗效
- main effect: 主效应
- negative effect: 负面影响；负效应；负磁力效应
- positive effect: 积极的效果；明显效果
