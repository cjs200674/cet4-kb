# apart

**释义**：成距离，相间隔；分开，除去； 分离的， 分隔的

**英文释义**：成距离，相间隔；分开，除去

**词性**：adv / adj

**搭配 / 词组**：

- apart from: 远离，除…之外；且不说；缺少
- fall apart: 崩溃；土崩瓦解；破碎
- set apart: 留出…；使分离；区别
- take apart: 拆开；剖析；粗暴对待
- come apart: 破碎；崩溃；瓦解
