# independent

**释义**： 独立的， 自主的； 无偏见的； 不相关联的

**英文释义**： 独立的， 自主的； 无偏见的； 不相关联的

**词性**：adj

**搭配 / 词组**：

- independent of: 不依赖…的；不受…支配的
- independent director: 独立董事
- independent thinking: 独立思考
- independent variable: 自变量；自变数
- independent study: n. 独立研究，独立学习
