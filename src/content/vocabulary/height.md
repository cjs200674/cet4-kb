# height

**释义**：高，高度；高处

**词性**：n

**搭配 / 词组**：

- in height: 高度，在高度上
- at the height of: 在…顶点；在…的顶峰或鼎盛时期
- wave height: 波形高度
- average height: 平均高度；中等身材
- in the height of: 在…的高潮中，在…的顶峰
