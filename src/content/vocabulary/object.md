# object

**释义**： 反对， 不赞成； 实物， 物体； 目的， 目标； 对象， 客体； 宾语

**英文释义**： 反对， 不赞成

**词性**：vi / n

**搭配 / 词组**：

- object oriented: 面向对象的；对象趋向的；物件导向的
- object of study: 研究对象
- object function: 目标函数；原函数
- controlled object: 被控对象，受控对象；控制对象
- material object: 实物
