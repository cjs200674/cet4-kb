# blade

**释义**： 刀刃， 刀片， 叶片

**英文释义**： 刀刃， 刀片， 叶片

**词性**：n

**搭配 / 词组**：

- leaf blade: 叶片
- saw blade: 锯片；锯条
- turbine blade: 涡轮叶片，透平叶片
- in the blade: 尚未结穗的；在萌芽状态的
- rotor blade: 转子叶片
