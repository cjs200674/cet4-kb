# council

**释义**： 理事会， 委员会

**英文释义**： 理事会， 委员会

**词性**：n

**搭配 / 词组**：

- state council: 国务院
- security council: （联合国）安全理事会
- city council: 市议会
- legislative council: 立法委员会（英国议会上院）
- executive council: 执行委员会
