# bounce

**英文释义**：弹起，反弹；颠簸

**词性**：v / n

**搭配 / 词组**：

- bounce back: 反弹；迅速恢复活力
- on the bounce: ◎在弹起时
- bounce the ball: 拍球
- bounce off: 弹开，反弹；从…弹跳出来；掂量…
- bounce up and down: 上下弹跳
