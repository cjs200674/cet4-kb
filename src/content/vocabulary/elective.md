# elective

**释义**：选举的，有选举权的；可任意选择的； 选修课程

**英文释义**：选举的，有选举权的；可任意选择的

**词性**：adj / n

**搭配 / 词组**：

- elective course: 选修课
- an elective course: 选修科目
- elective system: n. 选课制度，选修制
- elective subjects: 选修科目（elective subject的复数）
- elective surgery: 选择性外科手术；非急需施行的手术
