# overhead

**释义**： 在头顶上；在头顶上的，架空的； 经常费用， 管理费用

**英文释义**： 在头顶上

**词性**：adv / adj / n

**搭配 / 词组**：

- overhead transmission: 天轴
- overhead crane: 桥式吊车，高架起重机
- overhead transmission line: 架空输电线；高架输电线路
- overhead line: 架空线路；架空管道
- overhead projector: n. 高射投影仪
