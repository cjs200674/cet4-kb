# float

**释义**： 浮动， 漂浮； 飘动

**英文释义**： 浮动， 漂浮； 飘动

**词性**：v

**搭配 / 词组**：

- float glass: [化]浮法玻璃
- float on: 浮在…上
- float valve: 浮阀
- ball float: 浮球；球状浮子
- free float: 自由浮动；自由浮动时间；公众持股量
