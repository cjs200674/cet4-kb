# saddle

**释义**：鞍，鞍状物；车座； 给…装鞍； 使承担任务

**英文释义**：鞍，鞍状物；车座

**词性**：n / vt

**搭配 / 词组**：

- in the saddle: 掌权；在职
- saddle point: 鞍点
- saddle up: 备马；给马装上鞍
- for the saddle: (马等)供骑乘用的
- saddle horse: 驯马，骑用马
