# pulse

**释义**： 搏动， 跳动；脉搏；脉冲

**英文释义**： 搏动， 跳动

**词性**：vi / n

**搭配 / 词组**：

- pulse width: 脉冲宽度；脉冲持续时间
- pulse generator: 脉冲发生器
- pulse width modulation: [计]脉冲调制；脉宽灯；脉冲间隔灯
- pulse wave: 脉搏波；脉波
- pulse compression: [计]脉冲压缩
