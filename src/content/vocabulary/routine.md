# routine

**释义**： 例行的， 常规的；例行公事，惯例，惯常的程序

**英文释义**： 例行的， 常规的

**词性**：adj / n

**搭配 / 词组**：

- routine maintenance: 日常维修；例行维护
- routine work: 日常工作；常规作业
- daily routine: 日常生活；日常工作
- service routine: 服务程序
- routine analysis: 常规分析；例行分析
