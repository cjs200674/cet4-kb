# echo

**释义**： 重复， 模仿； 发出回声；回声；反响，共鸣

**英文释义**： 重复， 模仿； 发出回声

**词性**：v / n

**搭配 / 词组**：

- radar echo: 雷达回波
- echo cancellation: 回波消除
- ultrasonic echo: 超声回波；超声回声
- echo sounder: 回声测深器
- flaw echo: 缺陷回波；缺陷的回波信号；缺陷回声
