# flood

**释义**： 淹没； 涌入；洪水；大量

**英文释义**： 淹没； 涌入

**词性**：v / n

**搭配 / 词组**：

- in flood: 在泛滥
- flood control: 防洪；洪水控制
- flood in: 涌入，大量地涌到
- flood season: 汛期，洪水期；洪水季节
- flood prevention: 防汛；防洪；防洪工作
