# lock

**释义**：锁；锁上，锁住

**英文释义**：锁

**词性**：n / v

**搭配 / 词组**：

- lock up: 把…锁起来；关起来
- ship lock: 船闸
- lock in: 把……关在里面
- door lock: 门锁；车门锁
- lock on: 用雷达自动跟踪；锁住
