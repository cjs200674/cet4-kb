# coordinate

**释义**： 同等的， 并列的； 协调， 调节；坐标

**英文释义**： 同等的， 并列的

**词性**：adj / vt / n

**搭配 / 词组**：

- coordinate system: [数]坐标系
- coordinate with: 使协调；配合
- coordinate transformation: 坐标变换
- coordinate measuring machine: 坐标测量[检测]机；三元测定器
- polar coordinate: 极坐标；极座标；极坐标系统
