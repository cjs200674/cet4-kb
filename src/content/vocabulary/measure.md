# measure

**释义**：测量，度量；衡量； 分量； 尺寸； 量具； 计量单位； 量度， 测量； 措施， 办法

**英文释义**：测量，度量；衡量

**词性**：vt / n

**搭配 / 词组**：

- effective measure: 有效措施
- without measure: 过分
- austerity measures: 紧缩措施
- for good measure: 作为额外增添；另外
- technical measure: 技术措施
