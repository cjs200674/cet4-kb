# grab

**释义**：抓取，攫取；赶紧做；抓住；抓，夺； 抓， 夺

**英文释义**：抓取，攫取；赶紧做；抓住；抓，夺

**词性**：v / n

**搭配 / 词组**：

- up for grabs: 大家有份
- grab a bite: 吃点东西（非正式语）；随便吃几口；先吃点东西垫垫肚子
- grab at: 抓住，抓取；抓住不放
- grab crane: 抓斗起重机；抓斗吊车
- grab bucket: 抓斗，挖泥抓斗；抓岩机的抓斗
