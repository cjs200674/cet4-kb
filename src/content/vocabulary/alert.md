# alert

**释义**：警觉的，留神的，注意的；使认识到，使意识到； 警戒， 戒备； 警报

**英文释义**：警觉的，留神的，注意的

**词性**：adj / vt / n

**搭配 / 词组**：

- alert someone to sth: 使...警觉；使...警惕
- on the alert: 提防；警戒著；随时准备著
- red alert: 紧急警报，红色警报；应急状况
