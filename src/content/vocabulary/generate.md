# generate

**释义**：产生；发电；生成

**英文释义**：to produce or create

**例句**：
- Solar panels **generate** electricity.
- The project **generated** heated discussion.

**搭配**：
- generate electricity 发电
- generate income 产生收入
- generate discussion 引发讨论
- generate revenue 创造收益

**派生**：
- generation (n.) 一代人；产生
- generator (n.) 发电机
- generative (adj.) 生成的

**记忆法**：`gener`(产生，源于 genus) + `-ate` → 产生
