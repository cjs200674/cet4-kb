# instruction

**释义**： 命令， 指示； 用法说明； 教学， 教导

**英文释义**： 命令， 指示； 用法说明； 教学， 教导

**词性**：n

**搭配 / 词组**：

- classroom instruction: 课堂教学；课程设计
- instruction set: 指令组（表），指令系统
- work instruction: 作业指导；工作指令
- instruction manual: 安装手册，操作工序说明书；工艺规范
- working instruction: 操作说明书；工作细则
