# foot

**释义**：脚；最下部；英尺

**英文释义**：脚；最下部；英尺

**词性**：n

**搭配 / 词组**：

- on foot: 步行；在进行中
- at the foot of: 在…（山）脚下；在…的下部
- of foot: 在行走(或走路)中
- set foot on: 踏上
- set foot: 进入到某处；行走
