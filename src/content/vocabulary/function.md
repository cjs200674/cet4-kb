# function

**释义**： 运作， 运行；功能；职务，职责

**英文释义**： 运作， 运行

**词性**：vi / n

**搭配 / 词组**：

- and function: [计]与酌
- objective function: 目标函数
- system function: 系统功能；系统函数
- transfer function: 转移函数，传递函数
- basic function: 基本功能；基本函数
