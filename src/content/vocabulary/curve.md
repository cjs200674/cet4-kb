# curve

**释义**： 弯曲；曲线，弯，弯曲处

**英文释义**： 弯曲

**词性**：v / n

**搭配 / 词组**：

- curve fitting: 曲线拟合
- characteristic curve: 特性曲线；特征曲线
- elliptic curve: 椭圆曲线；橢圓曲線
- standard curve: 标准曲线
- growth curve: 生长曲线，增长曲线
