# pin

**释义**：针，饰针；别住

**英文释义**：针，饰针

**词性**：n / n

**搭配 / 词组**：

- pins and needles: 如坐针毡；焦躁不安；手脚发麻
- pin something on someone: [口语]把某事的责任加上某人身上，把某事归罪于某人
- on pins and needles: 如坐针毡；坐立不安
- pin down: 确定；使受约束；阻止
- piston pin: 活塞销
