# alarm

**释义**：惊恐；忧虑；警报； 使惊恐； 使担心

**英文释义**：惊恐；忧虑；警报

**词性**：n / vt

**搭配 / 词组**：

- alarm system: 报警系统
- fire alarm: 火警；火警警报器
- alarm clock: 闹钟
- false alarm: 假警报；引起一场空喜欢的人
- burglar alarm: 防窃报警器；防盗自动警铃
