# shoot

**释义**：发射；射中；发芽

**英文释义**：发射；射中

**词性**：v / n

**搭配 / 词组**：

- bamboo shoot: 竹笋，笋
- shoot at: 力争；向…射击
- shoot down: 击落；驳倒，否决
- shoot for: 争取，为…而努力
- photo shoot: 摄影；专业式拍照
