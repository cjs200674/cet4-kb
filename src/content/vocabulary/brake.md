# brake

**释义**： 制动； 刹住， 用闸使放慢速度；闸，刹车

**英文释义**： 制动； 刹住， 用闸使放慢速度

**词性**：v / n

**搭配 / 词组**：

- brake system: 煞车系统
- disc brake: [汽车]盘式制动器
- brake pad: 刹车片；盘式刹车片；制动衬块；闸垫
- brake pedal: 刹车踏板；制动踏板
- hydraulic brake: 液压制动器，液压式刹车器
