# order

**释义**：次序；整齐；命令

**英文释义**：次序；整齐

**词性**：n / v

**搭配 / 词组**：

- in order: 整齐，秩序井然；按顺序；状况良好
- order of: 约为，大约；订货；注尺寸顺序
- second order: adj. 二级的，二阶的
- first order: 一阶；初指令；第一级
- social order: 社会秩序
