# all

**释义**：全部的；全部

**英文释义**：全部的

**词性**：adj / prep

**搭配 / 词组**：

- all the: ◎惟一的，仅有的
- all of: adv. 不少于；实足
- in all: 总共，合计
- and all: 等等；的确；此外；连…一齐都
- all over: 到处，遍及；浑身；全部结束
