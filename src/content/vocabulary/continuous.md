# continuous

**释义**： 连续不断的； 延伸的

**英文释义**： 连续不断的； 延伸的

**词性**：adj

**搭配 / 词组**：

- continuous casting: 全连铸；连续浇铸
- continuous improvement: 持续改进；进取不懈
- continuous innovation: 连续创新
- continuous line: 实线；连续椎线
- continuous operation: 连续操作；连续运算
