# lane

**释义**： 小路； 跑道； 航道， 航线

**英文释义**： 小路； 跑道； 航道， 航线

**词性**：n

**搭配 / 词组**：

- fast lane: 快车道
- park lane: 柏宁酒店；花园弄
- bus lane: （街道上的）公共汽车专用车道
- memory lane: 往事感怀；分隔带车道；人生道路的轨迹
- traffic lane: 行车道；通车车道
