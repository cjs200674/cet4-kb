# if

**释义**：假如，如果

**英文释义**：假如，如果

**词性**：conj

**搭配 / 词组**：

- as if: 犹如，好似
- if any: 若有的话；即便要
- if so: 如果是这样的话；要是这样
- if only: 只要；要是…多好
- if ever: 假如，要是；如果真有(我当真)
