# diagram

**释义**： 图解， 图表， 简图

**英文释义**： 图解， 图表， 简图

**词性**：n

**搭配 / 词组**：

- block diagram: 框图；方块图
- phase diagram: [物理]（表示物质的各种相态平衡关系的）相图
- flow diagram: 流程图；作业图
- circuit diagram: 电路图；线路图
- schematic diagram: 原理图，示意图
