# mushroom

**释义**： 迅速成长；蘑菇

**英文释义**： 迅速成长

**词性**：vi / n

**搭配 / 词组**：

- straw mushroom: 草菇
- mushroom soup: 蘑菇汤
- mushroom cloud: 蘑菇云（热核爆炸后升起的）
- oyster mushroom: 平菇；蚝蘑；侧耳（等于oyster cap）
- button mushroom: 未长开的小蘑菇
