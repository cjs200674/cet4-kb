# treasure

**词性**：n / v

**搭配 / 词组**：

- treasure house: n. 宝库；宝藏室
- priceless treasure: 无价之宝
- treasure trove: n. 无主珍宝，无主埋藏物
- buried treasure: 宝藏；埋葬的宝藏；藏宝
- treasure chest: 财宝箱；宝库
