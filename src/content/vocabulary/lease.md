# lease

**释义**：租约，租契； 出租； 租得， 租有

**英文释义**：租约，租契

**词性**：n / vt

**搭配 / 词组**：

- lease contract: 租契；租赁契约
- lease term: 租赁期
- financial lease: 融资性租赁；财务租赁
- land lease: 批地契约；土地批租；土地契约
- financing lease: 融资租贷；筹资性租赁
