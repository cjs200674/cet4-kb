# collection

**释义**： 搜集， 聚集， 积聚； 收集， 收取； 收藏品， 收集的东西

**英文释义**： 搜集， 聚集， 积聚； 收集， 收取； 收藏品， 收集的东西

**词性**：n

**搭配 / 词组**：

- a collection of: 一批，一些；收藏的；许多的；集…为一体的
- data collection: 数据收集；资料收集
- collection system: 收集系统；拖收系统
- tax collection: 征税；税捐稽征
- dust collection: 收尘；集尘；吸尘
