# substitute

**释义**：代替；替代品；代用品

**英文释义**：to use something instead of something else; a replacement

**例句**：
- Honey can **substitute** for sugar in this recipe.
- Vitamin C is a good **substitute** for fresh fruit.

**搭配**：
- substitute A for B 用 A 代替 B
- substitute for 代替
- a substitute teacher 代课老师

**派生**：
- substitution (n.) 替代
- substitute (n.) 替代品

**辨析**：
- substitute "代替"
- replace "替换"
- swap "交换"

**记忆法**：`sub-`(在下) + `stitute`(站) → 站在下面 → 替角 → 代替
