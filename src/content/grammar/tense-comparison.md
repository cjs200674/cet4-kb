# 时态对比：现在完成 vs 一般过去

四级翻译、写作、阅读最高频的时态辨析。

## 🎯 核心区别

| 维度 | 现在完成时 | 一般过去时 |
|---|---|---|
| 时间关联 | 与现在有关 | 与过去某时间点有关 |
| 持续性 | 可表"持续到现在" | 仅表"过去发生" |
| 时间状语 | for / since / recently / so far | yesterday / last week / in 2020 |
| 结果 | 强调对现在的影响 | 只描述过去事实 |

## 📝 经典考题

**题目 1**：I ___ this book last weekend.
- A. have read
- B. had read
- C. read ✓
- D. am reading

**解析**：`last weekend` 过去明确时间，用一般过去时 → C

---

**题目 2**：I ___ this book since Monday.
- A. read
- B. have read ✓
- C. had read
- D. was reading

**解析**：`since + 起点` 必须用现在完成时 → B

---

**题目 3**：He has lived here ___ 2010.
- A. for
- B. since ✓
- C. from
- D. in

**解析**：`since + 时间点`，`for + 时间段` → B

## 🚨 高频考点

### 1. already / yet / just
- I **have already** finished my homework. ✓
- I have **not** finished my homework **yet**. ✓
- (不可用过去时)

### 2. ever / never
- **Have** you ever **been** to Beijing? ✓
- I **have never** seen such a sight. ✓

### 3. recently / lately
- I **have been** working hard recently. ✓
- (强调最近持续)

### 4. so far / up to now
- So far we **have collected** $10,000. ✓
- (强调到目前为止)

### 5. It is the first / second time...
- It is the first time I **have visited** Beijing. ✓
- (固定搭配：It is the + 序数词 + time + 现在完成时)

## ❌ 常见错误

| 错误 | 正确 |
|---|---|
| I have went there yesterday. ❌ | I went there yesterday. ✓ |
| I have seen him last week. ❌ | I saw him last week. ✓ |
| I lived here for 5 years. (还在住) ❌ | I have lived here for 5 years. ✓ |
| Did you ever eat sushi? ❌ | Have you ever eaten sushi? ✓ |

## 💡 一句话口诀

> **过去时配过去时间点，完成时配现在有关联。**
> 看见 since / for / recently / so far → 完成时。
> 看见 yesterday / last / ago / in 1990 → 过去时。

## 📚 翻译实战

**原句**：我自从 2020 年就开始学英语了。

**错误**：I began to learn English since 2020. ❌
**正确**：I have studied English since 2020. ✓

**原因**：`since + 起点` 是现在完成时的标志，"begin" 是一般过去时，两种时态冲突。

**原句**：他昨天去了北京，现在还没回来。

**正确**：He went to Beijing yesterday, and he **has not** come back **yet**. ✓
